# Security policy

This code moves real in-game money between a Paper server and a public
Minecraft server. Please report vulnerabilities privately instead of opening a
public issue: send a direct message to the maintainer on Discord (invite in the
README) or open a GitHub security advisory on this repository.

Please include a reproduction scenario. Money-affecting bugs (duplication,
quota bypass, acting on another player's account, prompt injection into the
AI desks) are treated as critical and fixed first.

Do not test against the production casino without permission.
